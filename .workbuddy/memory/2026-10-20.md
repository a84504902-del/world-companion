## 追加：应用 AI伴侣项目的「干巴巴」解决方案（v0.15.2）

用户反馈聊天回复干巴巴。方案来自 ai-companion 项目（用户在那边重新生成的记忆里有记录），
本项目脱胎于它，要把那边的解决办法搬过来。

### 根因（三层，全揪出来了）
1. prompts.json 的 length_modes 缺 normal 定义 + 前后端默认 normal → 等于不发送任何长度引导
2. 人设规则【L1·长度】写「情绪到位时两三句也行」+ 3 个一两句的短格式示例，把模型往短带
3. **DB 优先机制**：persona_store.active_persona() 先读 DB personas 表主角行（夏雪
   prs_xiaxue），库空才回退 JSON 文件 → 只改 JSON 文件对库里角色完全不生效

### 改动
- prompts.json：length_modes 补 normal 定义（80-150字）
- persona_anchor.json / persona_local.json：
  - speech_style/reply_format 加「像演电影一样第一人称带出动作、环境、感官细节」
  - 新【L1·长度】规则：跟随界面长度设置（短=一两句；标准=80-150；详=200-400充分展开）
  - 3 个短格式示例全换成长示例（沉浸式第一人称，100+字，保留原教学点）
  - local 亲密场景规则：诗意代称（小星辰/小云朵/小花瓣）可直白，详细描写动作感受
- routes/chat.py：length_mode 默认 normal → long，非法值兜底也 long
- static/js/chat.js / state.js：默认 'long'，加载时同步按钮选中态
- templates/index.html：长度按钮 active 从「标准」移到「详」
- DB prs_xiaxue 经 API 全量同步（GET→改 rules[7]+examples→POST 写回，save_persona
  是全量替换语义，不传的字段会被默认值覆盖）

### 验证
- 实测 3 次（length_mode=long）：149 / 231 / 182 字，全部第一人称带动作环境描写
  （修复前 73 字干巴巴）；测试会话已删，用户会话列表恢复原状
- 排查过但无问题的链路：会话 system_prompt 空、ENV SYSTEM_PROMPT 空、
  世界模板（wtpl_modern_family）无长度约束、max_tokens=2000 非瓶颈

### 教训（追加）
- 改人设必须三处同步：persona_anchor.json + persona_local.json + DB personas 表
  （DB 优先，改 JSON 对已有角色不生效——这次就是改完 JSON 实测仍 73 字才发现）
- 提示词里的长度压制器不止一处：长度规则 + 格式示例都会把模型往短带，要一起换

## 追加：人设双源问题收口（v0.15.3）

保留了「库空回退读 JSON」路径，但旧文件没删没标注——搬了新房子没退租。

### 改动
- persona_store.py：active_persona() 兜底读取打 warning（进程内只打一次）；
  新增 persona_source()（db/file/none）、import_seed_persona()（导入前自动全量
  备份到 backups/；已有主角就地覆盖、DB 专属字段 summary/age/bond_origin/
  user_name/world_template_id 保留原值，只刷新种子字段；库空新建 prs_xiaxue）
- routes/persona_api.py：新增 GET /api/personas/active（来源+警告文案）、
  POST /api/personas/import-seed。⚠️ 静态路由必须注册在 {id} 动态路由之前
- static/js/personas.js + style.css：人设面板顶部来源警告横幅 + 「从种子文件
  导入人格库」按钮（仅 source=file 时显示）；app.js 挂 window
- persona_local.json / persona_anchor.json：加 _note 字段标注「种子/备份基线」
- README：新增「人设生效源」小节（三名分表 + 两个接口 + 历史教训）
- VERSION 0.15.3

### 验证

- 打桩单测：库空时 from_file=True + warning 打出 + persona_source()=file ✓

## 追加：提示词收束进 prompts/ 文件夹（v0.16.0）

用户要求：提示词不许散落在代码里，必须有专属的家（形式不限）。
方案：prompts/ 文件夹按域分 5 个文件 + loader 升级 + 唯一例外留代码。
开工前用户专门确认了「怎么避免互相干扰」——为此设计了原子切换 checkpoint 流程。

### 结构
prompts/functional.json（功能型 7 key，原 prompts.json 原样搬入）
prompts/chat.json（4：group_rules / pov_full / pov_lite / pin_memory）
prompts/tasks.json（6：scene_* / loops_* / proactive_*）
prompts/onboarding.json（7：layer_1..5 / guider / preview）
prompts/memory.json（2：chunk_header / saved_header）
共 26 key。唯一例外：onboarding.py _GENERATE_PROMPT（1238 字含 JSON 格式示例，
搬进 JSON 会变一行转义字符串没法人读）留代码，已挂醒目标注。

### 机制（prompts.py）
- loader 扫 prompts/*.json 按文件名合并；任一文件 mtime 变化整体重读（热重载）
- 撞 key 打 warning（来源可查 prompts.prompt_source(key)）
- get_prompt 新增占位符缺失警告（同 key+占位符只警告一次）；
  顺手修了一个老漏洞：调用方完全不传 kwargs 时 {{占位符}} 会原样漏给模型，现在会清空+警告
- check_prompts.py 升级：读文件夹合并、死配置正则支持带点 key 和 f-string 动态 key
  （get_prompt(f"onboarding.layer_{layer}") 这种）、占位符检查改为通用规则
  （调用方传了即接线）
- 代码里的同名常量全部降级为 default 兜底（JSON 缺失时行为与旧版逐字一致）

### 验收方法（每个 checkpoint 都做了）
- diff 验收：从 backups/prompts_migration_20261020/ 提取旧常量，旧 .format 输出
  vs 新 get_prompt 输出逐字对比（CP2 曾抓到 3 处 JSON 示例结尾 }} 替换漏网，
  CP3 抓到转换脚本只覆盖了 layer 1-2——验收机制真的在干活）
- 来源探针：每个 key 的 prompt_source() 必须指向预期文件（防「default 兜底骗过验收」）
- check_prompts + 回归 94/94 + 冒烟（207 字、无 {{ 残留），每个 checkpoint 全绿才进下一个

### 踩过的坑（记一笔）
- get_prompt 的 while "{{" 清理循环会剥掉文案里字面的 {{...}} → JSON 示例必须
  写单大括号（functional.json state_card 是先例）
- .format 风格转 {{}} 风格时，`"}}` 结尾规则盖不住 `3}}`/`数}}` 这类非引号结尾
- 验收脚本正则要用非贪婪 (.*?)，贪婪版会跨常量抓取
- Python 的 /tmp 和 Git Bash 的 /tmp 不是同一个目录（Windows）

## 追加：借鉴豆包记录的「像人」手法灌进人设（第一轮+第二轮）

用户给了 D:\记录.txt（与豆包的对话记录），要求看「AI 更人性化的地方」。
讨论结论：七八成是可教的技巧（样例/规则能灌），两三成是模型底子（比喻品味、长段不散架）。
用户拍板先做第①条：提炼手法灌样例，迭代几遍。

### 灌进去的（三处同步：anchor/local/DB，DB 现共 28 规则 4 样例）
4 条新规则（插在【L1·可描写】后）：
- 【L1·环境是活的】环境跟人互动不是布景，换场景换感官包
- 【L1·带点小意外】东西会掉、会被打断，别太顺
- 【L1·铺以后】场景结束延伸未来+回扣之前聊过的
- 【L1·比喻少而新】一条最多一个新鲜比喻，禁排比堆修辞
1 条新样例（日常场景：环境参与+小意外+铺以后+回扣四合一）

### 实测（5 个不同话题，两轮）
「外面下雨了」208字：雨声砸雨棚+土腥味+衬衫白晒了+晚上接你顺路面馆（回扣）✓
「今晚吃火锅吧」258字：拖鞋甩飞+羊肉卷只剩一点+番茄锅惦记好久（回扣）✓
「今天好困」151字：剥橘子递一瓣+醒来买菜煮汤 ✓
「我回来了」240字：蒸汽蒙窗+抽油烟机+你妈打电话周末回家（带出关系网）✓
「帮我想想周末去哪玩」232字：芦苇「跟梳头似的」（唯一比喻且新鲜）+糖水铺惦记 ✓
手法全部泛化成功，未照抄样例，比喻零堆砌。
