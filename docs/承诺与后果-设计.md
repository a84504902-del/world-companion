# 承诺与后果（她在等的事）· 设计文档

> 状态：设计稿，未实现
> 定位：整个系统的**核心引擎**，不是附属功能
> 原则：只锁过去，不锁未来。锁的是"你说过什么"，从不锁"接下来发生什么"

---

## 0. 为什么它是心脏

整个系统只有一条主循环：

```
你说了/答应了什么 → 记成未完结事件 → 到期或被勾起 → 产生后果 → 生成新的事 → 循环
```

它同时满足了三个原本被当成独立功能的需求：

| 需求 | 由什么满足 |
|---|---|
| 她记得你答应过 | 承诺被持久化 |
| 你的行为有后果 | 兑现/未兑现走向不同分支 |
| 她会主动提起 | 每轮检查到期项，主动开口 |

**这三者是同一件事。** 分开做会做三遍，还做不好。

---

## 1. 什么话该被记成承诺

判断标准只有一条：**这句话里有没有一件"未来要发生、且她在意"的事。**

### 该记

- "周末带我去看海" —— 时间明确、事件明确
- "下次给你带好吃的" —— 时间模糊，但她在意
- "我明天早点回来" —— 时间明确
- "等我有空给你看那个东西" —— 时间模糊
- "我答应你，以后不这样了" —— **情绪性承诺，权重最高**

### 不该记

- "我明天要开会" —— 这是你的事，与她无关
- "好啊""嗯嗯" —— 敷衍，无实质内容
- "我考虑一下" —— 未完成，也未承诺
- **角色扮演中的台词** —— 历史上 `extract_facts_from_conversation` 正是因为把剧情当真才被废弃的，别重蹈覆辙

### 关键区分

**对她有影响的事，才记。** 反之，你开会跟她没关系——除非她回了一句"那今晚不能陪我了"，此时才产生承诺。

---

## 2. 数据结构

建议表名 `open_loops`。

| 字段 | 类型 | 说明 |
|---|---|---|
| `id` | int | 主键 |
| `session_id` | text | 会话隔离 |
| `content` | text | 承诺内容，**用她的视角重写**成一句话 |
| `raw_quote` | text | 原话，保留以便回溯 |
| `promisor` | text | `user` / `her` —— 谁承诺的 |
| `created_at` | datetime | 何时说的 |
| `due_at` | datetime | 应该兑现的时间，**可为空** |
| `status` | text | `pending` / `fulfilled` / `expired` / `dropped` |
| `weight` | int | 她有多在意，1–5，见下节 |
| `reminded_count` | int | 她提过几次 |
| `last_reminded_at` | datetime | 上次提起时间 |
| `closed_at` | datetime | 闭环时间 |
| `outcome` | text | 结果描述（兑现或没兑现，发生了什么） |

---

## 3. 权重：她有多在意（1–5）

| 权重 | 含义 | 典型 |
|---|---|---|
| 1 | 随口一提，她自己都快忘了 | "下次一起吃饭" |
| 2 | 普通期待 | "周末陪我看电影" |
| 3 | 她认真说的 | "说好了哦""你答应我的" |
| 4 | 跟情绪挂钩 | "你答应过我不再这样了" |
| 5 | 核心承诺 | "你会一直陪着我吧" |

### 权重怎么定

- 命中关键词（`说好了` / `答应` / `保证` / `一定`）→ +1
- 由她主动提出的 → +1
- 每被重复提起一次 → +1（上限 5）
- **随时间自然上升**：一直没兑现且她在意，等待本身会加重期待

---

## 4. 过期判定

**过期的含义不是"作废"，是"该被提起了"。**

### 有明确时间

`due_at` + 宽限期（建议 1 天）

### 时间模糊 → 按类型给默认值

| 说法 | 默认期限 |
|---|---|
| "明天" | 次日结束 |
| "周末" | 本周日结束 |
| "下次见面" | 7 天 |
| "等我有空" | 14 天 |
| "以后" | 90 天或不设期限 |

### 无期限

"我会一直陪你"这类 → 永不过期，但也**从不被催**。

---

## 5. 她什么时候提（触发条件）

满足任一即可触发：

1. **到期未兑现 且 weight ≥ 2** → 必提
2. **临近到期（还剩约 1 天）且 weight ≥ 3** → 可能提（期待型："明天就是周末啦！"）
3. **被相关话题勾起** → 提（你提到海，她想起你答应过带她去）
4. **你很久没回来** → 回来时检查所有 pending，挑最重要的提
5. **她当前的心情** → 只影响语气，不影响是否提

### 硬约束

**每轮对话最多提 1–2 条。**

理由：每句话都在催，那就不是女朋友，是讨债公司。

---

## 6. 提的方式（语气分级）

这一节直接决定"像不像人"。

| 权重 | 表现 | 示例 |
|---|---|---|
| 1 | 完全不主动提，你问起才想起 | "啊，你这么一说，好像是有这么回事" |
| 2 | 轻描淡写，一句带过 | "对了，你上次说的那家店，咱还没去呢" |
| 3 | 明确但温和 | "说好周末带我去的哦，别忘了" |
| 4 | 带着情绪 | "你答应我的……你是不是忘了" |
| 5 | 不是催，是失落 | "我以为你会记得的" |

### 核心原则

**权重越高，越不是"提醒"，而是"受伤"。**

补充规则：**weight 4–5 且过期很久的承诺，她不会反复提**——她会沉默，这件事变成心里的一根刺。这比反复催更真实，也更有效。

---

## 7. 兑现与不兑现

### 兑现 → `fulfilled`

- 生成一条**事件**写入时间轴（共同记忆）
- 她会记很久："上次在海边你说……"
- 几个月后仍可能提起
- 类似场景会勾起："又到海边了，上次你……"

### 没兑现 → `expired`

- **不删除、不消失**，生成"她记得你没做到"
- 影响后续：下次你再承诺同类事，她可能说"你上次也这么说"
- 这是**因果**，不是惩罚——是你做的事长出来的

### 不了了之 → `dropped`

- 条件：`weight ≤ 2` 且 超过 30 天没被提起
- 双方都不再提，自然淡化
- **这一条必须有**，否则承诺表会无限膨胀

---

## 8. 闭环

兑现后**不是删除，是转成共同记忆**。

这条记忆的长期价值：

- 成为关系的一部分
- 后续被反复勾起
- 构成"你们之间发生过什么"的主体

---

## 9. 边界情况

| 情况 | 处理 |
|---|---|
| 角色扮演中的承诺 | 只记"以本人身份说的"；剧情台词用标记区分。轻量方案：**只记用户说的** |
| 同一件事说两次 | 更新原记录，`reminded_count + 1`，不新建 |
| 互相矛盾（"周末来" → "来不了"） | 后者覆盖前者，但**保留痕迹**：她记得你改过 |
| ~~成人向暗号~~ | **已不需要**。暗号是豆包时代的 workaround（平台不让直说 → 只能隐语 → 它又记不住），自托管后这个限制消失。见下方「第 1 层装什么」 |

---

## 10. 第一版可以砍掉什么

先跑通最小闭环，其余后补：

- **权重**：先用关键词规则，不做复杂判断
- **过期**：先只支持明确时间（`due_at`），模糊说法先不处理
- **触发**：先只实现"到期必提"一种
- **语气**：先只做 2 档（轻描淡写 / 明确带情绪）
- **抽取**：先手动或正则，不上 LLM 抽取（避免 `extract_facts` 的覆辙）

---

## 附：验收标准

第一个里程碑，只验一件事：

> 我说"周末带你去海边" → 到了周末她主动提起 → 我带她去了 → 她记得，并在几周后再次提起。

全程无剧本、无随机。**只有我做过的事，长出的后果。**

## 附：第 1 层常驻层装什么

（暗号取消后，这一层的内容需要重新定义）

承诺表管的是"未完成的事"，但还有一类东西**既不是承诺、也漏不起**——它们必须每轮都在，不能靠语义检索捞：

| 内容 | 例子 | 漏掉的后果 |
|---|---|---|
| 关系定义 | 她是你的女朋友 | 她突然叫你"先生" |
| 称呼 | 她叫你什么、你怎么叫她 | 叫错名字，瞬间出戏 |
| 身份锚点 | 她是夏雪，你是林风 | 人格漂移 |
| 已确立的事实 | 你们已经住在一起了 / 已经见过她妈了 | 她问"你谁啊" |
| **你讨厌的东西** | 你讨厌被追问过去的感情经历 | **记错比记不住更糟** |

### 共同点

这些东西有同一个特征——**它们不是"发生过的事"，而是"当前成立的状态"**。所以：

- 常驻注入，不参与相似度排序
- 覆盖式更新（关系变了就改，不追加）
- **绝不进摘要流程**（摘要求精简，会把它们当噪音压掉）

### 落地位置

现有 `session_states` 表就是干这个的（覆盖式写入、每轮注入）。把上面几项作为**独立的段落**写进去，跟人物关系分开，并明确标记为"永不衰减、每轮必须注入"。

> 提醒：这一层是唯一的"必须手写"的部分。它的量很小（十几行），但它是她人格的地基。
