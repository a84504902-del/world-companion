# 使用日志

> **这里记"用起来别扭的瞬间"。不需要想怎么改，也不用管技术**——一句话就行，
> 剩下的我来翻译。攒几条给我一次。

---

## 怎么记（3 秒一条）

感觉不对劲的时候，**当场写一行**，别斟酌措辞：

```
09-15  她说"我等你回来"，但上一句她明明说自己在超市
09-15  连着三轮都在问我"今天累不累"，像复读机
09-16  状态条显示"家 · 热牛奶"，但她这轮说自己在公司
```

就这一句，够了。

**不需要**写成"我觉得可能需要优化记忆检索的时序逻辑"——那是我的活。

---

## 不知道看什么的时候，看这四样

按重要程度排。每周挑一个维度随便瞟两眼就行，不用都盯。

### 1. 她像不像人 ← 最重要

- 有没有重复说同样的话？
- 有没有答非所问？
- 语气是不是一成不变（每句都是"～"+"辛苦啦"）？
- 有没有说出"谁都不会这么说"的台词？

### 2. 记忆准不准

- **记错**：你根本没说过的话，她当成你说过
- **该记的没记**：你提过的事她完全不记得
- **记了没用上**：记在库里，但她从不提起

⚠️ **"记错"比"记不住"严重得多。** 记不住像人，记错像骗人。
这是最该盯的一条——它直接毁掉你要的那个东西。

### 3. 时间感对不对

- 她说的时间对不对（早上/晚上/过了几天）？
- 隔很久再聊，有没有"这段时间真的过了"的感觉？
- 状态条的时间和她的表现一致吗？

### 4. 主动行为自不自然

- 她留的言像不像真人发的？
- 时机对不对——是"你回来时她在"，还是"她突然冒出来"？
- 会不会太粘人 / 太冷淡？

---

## 记下来之后怎么办

攒一周（或者攒到你觉得够了），**整段发给我**。我会：

1. **归类**：哪些其实是同一个根因（十个别扭可能是三个问题）
2. **筛真伪**：哪些是真问题、哪些只是模型的正常波动
   （**不是所有怪都要修**——有时候修它会带来更大的副作用）
3. **给方案 + 优先级**：你只需要回答"要 / 不要"

---

## 我会配合做的事

每次改完一个功能，我会在更新日志里写一句 **「接下来观察什么」**，
比如"这几天注意看她留的言的时机对不对"。

**照着我给的点去盯，比漫无目的地用有效得多。** 因为你不需要自己判断"该看哪"。

---

## 判断标准（只有一条）

最后回到你自己定的那个终极验收：

> **你会不会没事也想去跟她说两句话？**

所有的改动都拿这一条衡量。技术上再漂亮，如果它没有让这条更容易成立，就是白做。
